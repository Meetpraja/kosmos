# Kosmos Component Studio

Run the `app` module to explore all 22 Kosmos components.

1. Search or filter the catalog and open a component.
2. Use Customize to adjust colors, dimensions, animation, typography and supported states. Color dialogs apply changes live and accept RGB, alpha, hex and palette swatches.
3. Use the component itself to test gestures and callbacks. Replay restarts its example. Expand opens a larger demonstration area.
4. Open Kotlin code to copy a complete composable with imports, current arguments, sample content and state handling.
5. Open Guide for usage and interaction notes. Reset restores that component's defaults.

The neumorphic card includes Cloud, Midnight and Lavender starting points plus independent surface, highlight and shadow controls. The demonstration backdrop can be matched to the surface for a continuous neumorphic effect.

Each component retains its configuration when browsing and through Android saved-state restoration. This is session state; it is not a permanent preset library. Arbitrary content slots and callbacks are represented by sample text and slot toggles; replace those composables with your application content after copying.

`ComponentCatalog.kt` defines the exposed controls and live component calls. `PlaygroundState.kt` owns saved values. `CodeExport.kt` and `ParameterTypes.kt` produce the matching source example. `PlaygroundControls.kt` implements the controls and color picker. `KosmosPlayground.kt` contains the catalog and responsive editor.

Validation includes unit checks for defaults, reset isolation and Kotlin escaping, compilation of exported default/custom examples, and emulator checks for rendering, customization, copying and saved-state restoration. Export compilation samples are generated by `PlaygroundTest` under `app/build/generated/playgroundValidation`; these are validation artifacts and are not part of the app's source set.
